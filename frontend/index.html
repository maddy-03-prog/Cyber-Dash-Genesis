MAINTAINER BRIEF: ABOUT DEVELOPER

ENGINEERING OVERVIEW

This web application showcases high-performance 2D canvas drawing techniques, custom programmatic sound wave synthesis, and complex state management using vanilla JavaScript. No heavy images or external audio assets are loaded, maintaining immediate loading speed and a stable 60 FPS profile.


ARCHITECTURE CHOICES

FSM State Engine: Distinct state loops separate Menu, Gameplay, Replay playback, and Photo capture vectors.

Dynamic Spawning: Procedural obstacle layout intervals decrease dynamically based on current run distance, and check for elevation gap jumps.

Synthetic Audio: The Web Audio API operates as a static sound wave scheduler, building basslines, hi-hat sweeps, and explosive filter sweeps on beat sequences.


PERFORMANCE OPTIMIZATION

Rendering Buffers: Multi-layered graphics rendering limits shadow blurs to high quality modes, ensuring mobile devices can play smoothly. Particles utilize a static recycle object pool to prevent browser memory leaks during runs.
